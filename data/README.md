# Training data

- `features.csv` is the real labeled dataset: one row per flow, aggregate packet
  statistics only (no addresses, no payload). Older rows have no `session_id`, so
  they cannot be held out by whole session.
- To add new, independent sessions: record captures with tcpdump, Wireshark or
  dumpcap while doing only one activity, save them as
  `captures/<label>/<session-name>.pcap`, then run
  `python scripts/build_dataset_from_pcaps.py captures/ --append` and
  `make train`. Without `--append` the script refuses to touch an existing CSV.
- `synthetic_sessions.csv` is generated by `scripts/generate_samples.py` and is only
  used by the anomaly model and the synthetic experiments. Never report it as real
  classifier accuracy.
- The classifier's training rows all carry the same value (1.0) for `max_concurrent_flows`, because that feature was added after the data was recorded. A Random Forest cannot split on a constant column, so the classifier effectively learns from 33 of the 34 features. The anomaly model is fitted from pcaps and does use the feature.
